# 할 일 관리 앱 PRD

## 1.Why - 목적

- 일일 할 일을 주간 계획 → 1년 목표로 연결해 목표 달성 과정 가시화
- 할 일 상태 변경만으로 주간·1년 진행률 자동 갱신 (수동 집계 제거)
- 드래그 앤 드롭으로 상태 변경 조작 단순화

## 2.Who - 타깃 사용자

- 1년 목표를 주간·일일 단위로 나눠 실행하려는 개인 사용자
- 칸반(todo/doing/done) 방식으로 할 일을 관리하려는 사용자

## 3. User Flow

1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표에 연결
3. 할 일 생성 → 날짜 지정, 주간 계획에 연결
4. 칸반 보드(todo/doing/done)에서 이번 주 할 일 확인
5. 할 일 카드를 드래그 앤 드롭 → 상태 변경
6. 연결된 주간 계획 진행률 → 1년 목표 진행률 순으로 자동 갱신
7. 할 일 수정/삭제 → 진행률 재계산

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **할 일 CRUD**
  - 생성: 제목(필수), 날짜(필수), 상태(기본값 todo), 주간 계획(선택)
  - 수정: 제목, 날짜, 상태, 연결 주간 계획 변경
  - 삭제: 삭제 즉시 연결 주간 계획·1년 목표 진행률 재계산
- **상태 관리**
  - 상태값: `todo` / `doing` / `done`
  - 모든 상태 간 양방향 전환 허용
- **칸반 보드**
  - 컬럼: todo / doing / done
  - 기본 표시 범위: 이번 주(월~일) 날짜의 할 일
  - 컬럼 내 정렬: 날짜 오름차순, 같은 날짜는 생성순 (수동 순서 변경 없음)
- **드래그 앤 드롭 상태 변경**
  - 카드를 다른 컬럼에 드롭 → 해당 상태로 변경
  - 드롭 즉시 저장 + 진행률 반영
- **기간 구조**
  - 일일: 할 일 (날짜 단위)
  - 주간: 주간 계획 (월요일 시작 ~ 일요일 종료, 7일 고정)
  - 1년: 1년 목표 (연도 단위)
  - 주간 계획 / 1년 목표 생성·수정·삭제
  - 주간 계획끼리 기간 중복 불가
- **구조 연결 (할 일 → 주간 계획 → 1년 목표)**
  - 할 일 : 주간 계획 = N : 1
  - 주간 계획 : 1년 목표 = N : 1
  - 할 일 날짜가 주간 계획 기간 내일 때만 연결 허용
  - 주간 계획은 시작일(월요일)이 속한 연도의 1년 목표에만 연결 허용 (연도 경계에 걸친 주 포함)
  - 주간 계획 삭제 시 연결된 할 일은 유지, 연결만 해제
  - 1년 목표 삭제 시 연결된 주간 계획은 유지, 연결만 해제
- **연결 정합성 유지**
  - 할 일 날짜 수정으로 연결 주간 계획 기간을 벗어나면 → 연결 자동 해제 + 사용자 안내
  - 주간 계획 기간 수정으로 기간 밖이 된 할 일 → 연결 자동 해제 + 사용자 안내
  - 주간 계획 기간 수정으로 시작일 연도가 바뀌면 → 1년 목표 연결 자동 해제 + 사용자 안내
- **주간 진행률 자동 반영**
  - 계산식: (연결된 할 일 중 `done` 수 ÷ 연결된 할 일 전체 수) × 100
  - 갱신 트리거: 할 일 생성 / 상태 변경 / 연결 변경(자동 해제 포함) / 삭제
  - 연결된 할 일 0개 → 0% 표시
- **1년 목표 진행률 자동 반영**
  - 계산식: 연결된 주간 계획 진행률의 평균
  - 연결된 할 일이 0개인 주간 계획은 평균 계산에서 제외
  - 계산 대상 주간 계획 0개 → 0% 표시
  - 갱신 트리거: 연결된 주간 진행률 변경 / 주간 계획 연결 변경(자동 해제 포함) / 주간 계획 삭제

### P1 - 추가 기능

- 기간별 뷰 전환: 일일 / 주간 / 1년
- 미연결 할 일 목록 표시
- 할 일 필터: 상태 / 날짜 / 주간 계획 기준
